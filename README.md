Affordable student accommodation in Newcastle.

## About this website

Tyne Student Lets is a fictional educational simulation for Northumbria
University's Cyber Clinic. No accommodation is offered, no payments are taken,
and no personal information is collected.

The website uses static HTML and CSS, with an original property illustration
stored locally in `assets/`. It has no build step or external dependencies.
